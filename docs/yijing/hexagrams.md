# 六十四卦

## 单卦笔记模板

复制下面这段，改标题和内容即可。

```markdown
## 第 XX 卦 · 卦名（上卦下卦）

**卦象**：☰ 上 / ☷ 下 —— 用一句话描述画面
**卦辞要义**：不超过 30 字
**爻辞要点**：只记最关键的 1-2 爻
**取象**：自然、人事、身体各举一例
**我的案例**：某年某事，结果如何（写完再回看准不准）
**存疑**：不理解的句子
```
