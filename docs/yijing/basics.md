# 基础概念

## 术语卡模板

每学一个概念，用这个模板写一张卡片，半年后你自己能看懂。

| 项目 | 内容 |
| --- | --- |
| 术语 | 例：体用 |
| 出处 | 哪本书、哪一卷、哪一页 |
| 一句话定义 | 不超过 40 字 |
| 我的理解 | 用生活里的例子说一遍 |
| 易混淆 | 和哪个概念容易搞混，区别在哪 |
| 待验证 | 我还不确定的地方 |
