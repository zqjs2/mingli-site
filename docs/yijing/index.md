## 学习路径（建议顺序）

1. 先分清**卦、爻、象、辞**四个层次，别一上来就背卦辞
2. 再看**八卦取象**与**先后天方位**，这是后面风水的接口
3. 然后按**上下经**顺序过六十四卦，每卦只记三件事：卦象、核心义、一个生活化的例子
4. 最后再进入**占筮方法**，方法本身不难，难的是解卦的取舍
