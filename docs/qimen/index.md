# 奇门遁甲

## 为什么学它

奇门是“时间 + 方位 + 人事”的三维模型，和八字看人、风水看地，正好互补。学它是为了多一个判断角度，不是为了速成“断事”。

## 学习顺序（定死）

1. **基础符号**：九宫、八门、九星、八神、三奇六仪
2. **排盘**：拆补法 / 置闰法，先手工排三局打底
3. **格局**：常见吉格凶格的识别
4. **用神取法**：问什么、取什么
5. **实战**：每次断事记录“问什么—排盘—判断—结果”
