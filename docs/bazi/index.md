# 四柱八字

## 推演顺序（固定下来）

学习最怕乱序。我固定按这个顺序推，避免每次都从头想：

1. **排盘**：定年月日时，换干支，标藏干
2. **定日主强弱**：得令、得地、得势
3. **取用神**：扶抑、调候、通关
4. **看格局**：正格、变格
5. **看大运流年**：何时应、应何事
6. **写结论**：只写有依据的部分，不确定的单列"存疑"
