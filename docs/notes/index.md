# 子清手记

我是子清。这里是随手记下的东西——读到的、没想通的、后来又想通的，都按原样留着，不修饰，方便回头对照自己是哪一步开始明白的。

## 三类笔记，分开存

| 类型 | 用途 | 写法 |
| --- | --- | --- |
| **读书摘录** | 保留原文与出处 | 摘 + 出处 + 页码，不改写 |
| **术语卡** | 快速回忆 | 一张卡一个概念，40 字以内 |
| **疑问清单** | 驱动下一步学习 | 只写问题，不急着写答案 |
