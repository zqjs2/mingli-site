# 明理斋 · 易学与命理笔记

记录学习 **易经、风水、四柱八字、奇门遁甲、面相学** 的过程：基础概念、读书摘录、真实命例，以及自己也还没想明白的问题。

学习最怕两样：记在本子里找不到，过几个月忘得干净。所以这里只有一条原则——

> 先把问题写清楚，再去找答案；写过的东西，要能被自己搜出来。
