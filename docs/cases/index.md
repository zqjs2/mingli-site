# 命例库

## 为什么要单独建一栏

理论看过就忘，案例会留在记忆里。更重要的是：**案例能反过来检验理论**，也能暴露自己的偏见。

## 记录模板

```markdown
## 案例编号 · 一句话概括

**基本事实**
- 出生：公历 ×××× 年 ×× 月 ×× 日 ×× 时（注明真太阳时是否校正）
- 地点：×× 省 ×× 市
- 性别：

**四柱**
年柱 ／ 月柱 ／ 日柱 ／ 时柱

**可核实的人生节点**
- ×× 年：上学 / 工作 / 婚恋 / 迁移 / 健康（只写当事人确认过的事实）

**当时的推断**
推断内容、依据哪条规则

**事后回看**
准的部分 / 不准的部分 / 我当时忽略了什么

**存疑**
```
