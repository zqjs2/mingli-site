# 面相学

## 核心思路

以五官、三停、十二宫为框架，讲“形—气—神”的观察顺序：先看整体格局，再落局部。

## 学习清单

- [ ] 三停（上停、中停、下停）与年龄段对应
- [ ] 五官取象（眉、眼、鼻、口、耳）
- [ ] 十二宫（命宫、财帛、兄弟、夫妻等）的位置
- [ ] 气色与神态的观察方法（这部分最难，靠积累）
- [ ] 与八字的对照：同一特征两套体系怎么说

## 记录建议

看相笔记要有**照片（经本人同意）**或**手绘示意图**，只写文字，三个月后自己都想不起当时看到什么。

!!! warning "边界"
    只做学习与观察记录，不做健康诊断，不给人下吉凶断言。
