# 天星风水学习路径

天星一派（赖布衣一脉）以**二十八宿定吉凶**为骨，核心典籍是《催官篇》，断法集大成者是清代张九仪的《地理四弹子》。这条线的学习顺序，和三元、玄空那套"先排盘再断"完全不同：**先看形势，再上罗盘，最后才谈星度**。

## 阶段一：形家打底（峦头）

**目标**：拿到一块地、一间房，先能看出"形"的吉凶，不靠任何盘。

- 读：《雪心赋》《入地眼》《地理人子须知》形法部分
- 练：四势（青龙、白虎、朱雀、玄武）、穴星九变、砂法水法、结穴证佐
- 坑：跳过形家直接学星度，是这一派最常见的走偏——峦头不真，理气无用

## 阶段二：罗盘与分金

**目标**：罗盘每一层能自己讲出用途，不背口诀。

- 必掌握：地盘正针、七十二穿山、六十透地、二十八宿分度、一百二十分金
- 读：张九仪《穿山透地真传》；工具书用许绍龙《罗经的使用方法》
- 练：拿自家住宅、祖坟实地量一遍，记录坐向、宿度、分金
- 坑：只知道"度数"，不知道"宿度"；天星断吉凶用的是二十八宿，不是单纯的角度

## 阶段三：《催官篇》精读

**目标**：能逐句翻译成"龙怎么来、砂怎么配、水怎么收、向怎么立"。

- 读：赖布衣《催官篇》＋张九仪《地理四弹子》（铅弹子最实操）
- 练：每读一段，画一张示意图，把文中龙穴砂水落到实际地形上
- 坑：只背结论不画图；催官篇的价值在"配对关系"，不在字句

## 阶段四：断法与案例

**目标**：从"看得出"到"断得准"，能复述已验案例的推理链。

- 读：张九仪《地理四弹子》案例卷；台版形家讲义里的实照案例
- 练：每看一个案例，先自己下判断，再对照书上结论，记录错在哪里
- 坑：形家和理气混着断，同一块地得出两套结论——形家可广采，理气只认一门，两边分开记

## 和三元、玄空的关系

天星论向、论水自有一套，和玄空挨星、玄空大卦的结论常不一致。站里的「三元风水」「玄空大卦」两个板块，只作**对照参考**：知道人家在讲什么即可，不拿来校核自己的天星盘。
