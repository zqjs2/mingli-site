# 天星风水

## 核心思路

天星一脉（赖布衣传承）以二十八宿、九星配方位，讲究“天、地、人”相应。核心典籍是赖布衣《催官篇》，断法以清代张九仪《地理四弹子》为集成。学法上先看形势，再上罗盘认星，最后才议向。

## 学习清单

- [ ] 二十八宿与十二分野的对应
- [ ] 九星（贪狼、巨门、禄存、文曲、廉贞、武曲、破军、左辅、右弼）的基本性
- [ ] 星与二十四山的配合逻辑
- [ ] 与三元、玄空的差异点：星为先还是卦为先
