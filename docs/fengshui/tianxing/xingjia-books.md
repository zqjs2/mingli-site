# 形家书目

形家（又称长眼法、峦头法）管的是"形"——物体形态、空间位置与人物的对应关系，断得直接，不排盘。这一页把**公版古籍**和**台湾三位老师**的书放在一起，标清版本、价格、读法。

## 二、刘贲（刘賁）· 进源书局

刘贲是进源书局的专职作者，著作四十余种，**形家只占两种**，正好是你需要的部分：

| 书名 | 出版 | 定价／优惠价 | 定位 |
| --- | --- | --- | --- |
| 陽宅形家透析 | 2013-08，進源 | NT$550／468 | 阳宅形家主册，内外峦头通论，560 页 |
| 陽宅形家透析・內巒頭 | 2013-09，進源 | NT$500／425 | 内局专篇，室内格局与形煞 |

读法：先《陽宅形家透析》通读建立框架，再用《內巒頭》查细目。他的长处是"把形家体系理出一条逻辑的路子"，配图多、能自学；短处是偏现代城市住宅，古法案例少。

其余三元、玄空、挨星那批（玄空大卦透析、玄空挨星透析、九运阳宅透析等）属理气，不作为主线。

## 三、陈义霖（陳義霖）· 长眼法一脉

形家长眼法的传承脉络：**和尚师 → 郑清风 → 刘宝卿、陈义霖**等。陈义霖与黄连池合著、以及独立署名的几本，是这一脉公开出版最多的：

| 书名 | 说明 |
| --- | --- |
| 形家讲堂—非看不可 | 三分单元：形家四势与判断、图说＋实照拆解、形象预测学与内局调理 |
| 阳宅实务—非看不可 | 阳宅实操，与《形家讲堂》同一编排原则 |
| 阴宅造葬实务—非看不可 | 阴宅造葬流程与判断 |
| 形家阳宅配三元纳气诊断旺衰 | 与黄恒堉、林定荣合著，形家配三元纳气，做"峦头＋理气"对照用 |

读法：他的书以"理论、教学、实务"三段式编排，实照多，适合照着照片练眼。注意他书里已带入三元纳气，读时把"形家判断"和"纳气判断"分开记，别混成一套。

## 六、三位老师怎么分工读

- **刘贲**：搭框架、理体系，现代阳宅形家的"教科书"
- **陈义霖**：练眼、对实照，长眼法一脉的公开教本
- **刘宝卿**：看断语口径、看原味讲义，属于"进阶层"

顺序建议：刘贲打框架 → 陈义霖练实照 → 刘宝卿补断语。中间随时回古籍（雪心赋、入地眼）校准，避免只学现代人的转述。
