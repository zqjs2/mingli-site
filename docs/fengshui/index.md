# 风水

## 两条主线，先分开

- **形法**：看山、看水、看局，重实地观察
- **理气**：罗盘、方位、飞星、卦运，重推算

两条线分开记，别混在一段话里，否则以后自己都分不清哪句是看的、哪句是算的。

## 学习顺序建议

先 **八卦风水** 打底（术语最少、见效快），再上 **一宅断**（实战），然后进 **三元** 与 **玄空大卦**。**天星** 可以并行，但要先备好星宿对照表。
