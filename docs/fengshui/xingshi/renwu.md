# 台湾形家诸家：人物、特点与书目

形家（峦头法、长眼法）管的是「形」——物体形态、空间位置与人物的对应关系，断得直接，不排盘。这一页不立某一家为主线，而是**按人排**：谁、属于哪一路、特点是什么、有什么书可看。

## 一、先分清四路

| 路线 | 做法 | 代表 |
| --- | --- | --- |
| 长眼法一脉 | 不用罗盘，纯看四势、形煞、内外局 | 郑清风一系及其弟子 |
| 体系整理型 | 把形家写成现代教科书，配图、分章 | 进源书局一批作者 |
| 形家＋理气混合 | 形家断形，纳气断气，两套并记 | 陈义霖与黄恒堉、林定荣合著那本 |
| 古籍形法 | 直接读明清峦头经典 | 雪心赋、入地眼、人子须知等 |

四路不是高下之分，是**入手方式**不同：长眼法见效快、古籍立骨稳、体系书好教学。

## 二、长眼法一脉：和尚师 → 郑清风

据这一脉自述，长眼法是 1949 年前后由一位无名号、只称「和尚师」的人带到台湾，郑清风得传后**正式命名为「地理长眼法」**，简称长眼法——意思是「擅用眼力观察论断地理形势」。

- **郑清风**（外号「泥鳅仙」）：看阴阳宅不用罗盘，只凭眼看形势与形煞。没有正式出版的著作，学问靠开班授徒、弟子讲义与口传流布
- **这一脉的分水岭**：从「以形断事」出发，不看方位理气，四势（龙虎、明堂、水口）与形煞直接对人事

## 三、第二代与再传：按人看特点

| 人物 | 特点 | 代表作 | 备注 |
| --- | --- | --- | --- |
| 刘宝卿 | 郑清风弟子，讲义体、信息密度最高，断语口径最「原味」 | 《形家长眼法阳宅阴宅风水上课讲义》2015，進源，NT$2500／2250 | 排版粗、价高，宜整套看或借阅 |
| 陈义霖 | 郑清风弟子；理论／教学／实务三段式编排，实照多，适合照照片练眼 | 《形家讲堂—非看不可》《阳宅实务—非看不可》《阴宅造葬实务—非看不可》；与黄恒堉、林定荣合著《形家阳宅配三元纳气诊断旺衰》 | 早年从潘养和学三元纳气，书里已带入纳气，读时「形断」「气断」分开记 |
| 黄连池 | 与陈义霖合著，偏教学整理 | 同上《形家讲堂—非看不可》 | 合著署名 |
| 吕茂宏 | 长眼法另一支，讲义体系完整（约六百页彩色讲义，流传广、非正式出版物） | 长眼法讲义（讲义本） | 入手不易，多为影印流传 |
| 黄诚宗 | 师承吕茂宏，把这一支整理成正式出版物 | 《形家阳宅地理学·长眼法》 | 市面上少见的「吕系」成书 |
| 王承纬 | 建筑背景，陈义霖弟子，在大陆执业 | 无专著，见公开访谈 | 据媒体访谈，非学术定论 |

读法建议：**陈义霖练眼（实照多）→ 刘宝卿补断语口径（讲义原味）**；吕茂宏、黄诚宗那支作为对照，看同一形在不同人嘴里怎么断。

## 四、体系整理型：把形家写成教科书

这一路的特点是**理出一条逻辑线**，配图多、能自学；短处是偏现代城市住宅，古法案例少。

| 书名 | 说明 | 定价参考 |

| 陽宅形家透析 | 阳宅形家主册，内外峦头通论，560 页，2013-08 進源 | NT$550／468 |
| 陽宅形家透析・內巒頭 | 内局专篇，室内格局与形煞，2013-09 | NT$500／425 |

## 六、按目的选路线

- **想快点能断、给客人讲得明白** → 长眼法：陈义霖的实照 → 刘宝卿的断语
- **想搭体系、以后教学** → 体系整理型那两本
- **想立骨、不被现代人转述带偏** → 古籍五本，先雪心赋、入地眼
- **想形气对照** → 陈义霖、黄恒堉、林定荣那本，但务必分栏记
