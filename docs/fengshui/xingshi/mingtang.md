# 明堂与水口：一个地的「院子」和「门户」

上一篇把龙脉从祖山排到穴心，落在方寸之间。这一篇往前看一步：穴前那片地（明堂）和出水那个口（水口）。这两处定了，一个地的形势骨架就算完整。

## 一、明堂分三层，以穴为准

明堂不是「越大越好」，是**离穴远近各有各的用**。分三层：

<a href="../../../assets/fengshui/mingtang-tu.png" target="_blank"><img src="../../../assets/fengshui/mingtang-tu.png" alt="明堂三格" width="100%"></a>

| 层次 | 范围 | 要点 |
| --- | --- | --- |
| 小明堂 | 穴下贴身 | 能容拜跪起坐便是，不必求大 |
| 中明堂 | 龙虎之内 | 宜平正、开阔、无遮拦、不被水冲 |
| 大明堂 | 龙虎之外、案山之内 | 宜宽阔容众，所谓「容万马」 |

口诀是「**内局紧、外局宽**」：贴身紧才聚得住，外围宽才容得下。反过来的地——贴身空旷、外围逼窄——看着气派，其实散。

### 明堂四忌

1. **水劫**：水直冲堂心，或从堂心穿破而出
2. **反弓**：水或砂走成向外弯的弧形，抱不住
3. **逼窄**：四面压过来，堂中无容身之地
4. **割脚**：水贴穴脚流过，根脚被削

这四条都是**看得见的形状**，不必等断验，站在穴上一眼就能记下来。

## 二、水口：一地的门户

明堂是院子，水口是门口。众水汇齐往外走的那一处，古称「天门」。

<a href="../../../assets/fengshui/shuikou-tu.png" target="_blank"><img src="../../../assets/fengshui/shuikou-tu.png" alt="水口关锁" width="100%"></a>

水口看得就是两个字：**关锁**。关锁的凭据有五样：

- **捍门**：水口两侧特起的山，如门之两扇，两山对峙最好
- **华表**：水口两侧的石柱、石峰，像门柱
- **罗星**：水口之内突起的小丘，如星镇口，不在口外而在口内为贵
- **北辰**：水中特立的大石，镇口之重物，最难遇
- **下手砂**：出水那一侧兜回来的砂，能逆转水势、把水口收小的为上

再加上一些小石小墩，叫**禽星**，也作关锁看。

反过来，**水口空阔、直去无收、一望无拦**，就是一地漏气的地方——这是形势上可以指出的缺陷，不必扯到吉凶。

## 三、水形五种，只看走法

| 水形 | 形状 | 形势评价 |
| --- | --- | --- |
| 之玄水 | 来去曲折如「之」如「玄」 | 来不见源、去不见尾，最耐看 |
| 环抱水 | 弯抱穴场，如玉带 | 有情，抱得住 |
| 横过水 | 横向从堂前过 | 看宽度与远近，忌贴脚 |
| 斜飞水 | 斜穿而过，两边不等 | 一边受水一边不受，气不匀 |
| 直冲、反弓 | 直撞堂心，或向外弯 | 冲、割、走，都属形势之病 |

判断顺序：**先看它抱不抱、再看出不出得慢、最后看离穴脚多远**。水近而缓、弯而抱，是形势上的好；至于是不是「发」，那是另一层，不在图上说。

## 四、砂的层级：官、鬼、禽、曜

龙虎只是内圈。往外还有一层一层的砂：

- **案山**：穴前最近的横山，如几如案，管「关」，把堂气兜住
- **朝山**：案山之外的远山，管「望」，主一方气象
- **官星**：穴后（或案后）特起之山，如官之仪仗
- **鬼星**：穴后拖出的小山，撑住穴背，叫「鬼撑」
- **禽星**：水口或龙虎外侧的小石小墩
- **曜星**：龙虎嘴尖、砂头尖利外露者，尖而不恶为曜，尖而破碎为煞

这四个（官鬼禽曜）是形家看「贵气」的常用词，说到底是**砂的余气**——主山有余力，才会在外面冒出这些小山小石。所以看图时先认主从：**谁是主、谁是余**。

## 五、一个地的基础信息：十二项清单

到这里，从祖山到水口，一套看地的骨架齐了。实地走一遍，按这张表记事实，不下断语：

| 序 | 项 | 看什么 |
| --- | --- | --- |
| 1 | 祖山、少祖山 | 来脉的源头与分派，气势是否连续 |
| 2 | 父母山 | 穴后贴身之山，是否紧贴、有无断陷 |
| 3 | 过峡 | 束气处：夹、细、隆、护；忌凿断、水冲、阔大 |
| 4 | 入首 | 最后一节落脉，是直落、横落还是闪落 |
| 5 | 穴星 | 结穴之山形：圆、方、尖，与窝钳乳突的配合 |
| 6 | 穴证 | 球檐、太极晕、蝉翼、虾须、蟹眼、氊唇、界水 |
| 7 | 小明堂 | 贴身有无小坪，是否被水割脚 |
| 8 | 龙虎 | 内抱是否有情，有无反跳、逼压、空缺 |
| 9 | 中明堂、大明堂 | 平正开阔，有无遮拦、水劫、反弓 |
| 10 | 案山、朝山 | 案是否兜得住，朝是否端正、有无破碎 |
| 11 | 水（水城） | 来去之形：之玄、环抱、横过、斜飞、直冲 |
| 12 | 水口 | 捍门、华表、罗星、北辰、下手砂，关锁是否严密 |

十二项里，1–5 是**来脉**，6 是**穴本身**，7–9 是**堂局**，10–12 是**砂水**。四组各有各的看头，缺一组，判断就悬空。

## 六、这一套图的用法

三篇连起来是一张「从大山到方寸」的降维图：

1. 先在《龙穴形势总图解》里定位：这条龙走到哪、穴在哪
2. 再到《过峡》看这一节有没有过关
3. 然后《穴之微形》确认脚下真有穴证
4. 最后这一篇，看院子（明堂）和门口（水口）收不收得住

图上都只标位置与关系，不落吉凶断语。形家的功夫在**实地尺度、方位、水流的配合**上，图只能给「词」和「序」。
